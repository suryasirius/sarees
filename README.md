# Traditional Threads

Catalogue website for a WhatsApp-based saree business. One page, mobile-first, no build step.

## Edit
- **Brand name and WhatsApp number:** the `CONFIG` block near the top of the script in `index.html`.
- **Sarees:** the `SAREES` list just below it (name, price, description, fabric, code).
- **Photos:** currently drawn placeholders. Real photos will replace them.

## Host on Vercel
Import this repository in Vercel. No settings needed: it serves `index.html` as a static site.
